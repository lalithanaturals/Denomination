Settings

Business Profile

This is a general-purpose shift register — anyone installing this file can rebrand it for their own shop by changing the name and logo here. Nothing else in the app needs to change.

Updates the header live as you type — click Save Settings to keep it.

Shown under the business name on printed A4 reports and thermal receipts, when set. Left blank, it's skipped — nothing prints in its place.

Also shown under the business name on printed reports/receipts, when set. Left blank, it's skipped.

Branches

The list of branches/outlets this register is used for. Add, rename, or remove them here — every branch dropdown in the app (register, filters, WhatsApp groups, comparisons) follows this list.

Useful when a laptop or tablet always stays at one branch — staff can't accidentally pick the wrong one.

Default Fields

Whatever names you set here become the defaults every time a new (or cleared) register is opened — so a new business can rename these to match their own expense categories, owners, vendors, etc. instead of using ours.

These rows always appear in the Expenses table (name is fixed per shift, only the amount is entered).

These rows always appear in the Owner Bills table.

Optional. These pre-fill the Vendor Payments table on a fresh register — cashiers can still edit the name or add more rows. Leave empty for a single blank row.

Optional. These pre-fill the Staff Bills table on a fresh register — cashiers can still edit the name or add more rows. Leave empty for no rows to start.

Optional. Pre-fills the Unbilled Sell table on a fresh register the same way. Leave empty for a single blank row.

Shifts

The list of shifts offered in the register header's Shift dropdown. Add, rename, or remove them here, or turn shifts off entirely for a business that only ever runs one shift a day.

Cash Bill Settings

Options for the Cash Bill (mini POS) screen.

Used the first time Cash Bill is opened on a device — after that, the last payment mode used takes over.

Paper width used for both the Cash Bill receipt and the register's Thermal Printer export. Takes effect on the next print.

Clears every barcode-remembered item name/price/discount used by Cash Bill, so scanning any barcode again is treated as brand new.

Alerts

Shifts with a tally mismatch larger than this amount are highlighted in Show Records so they're easy to spot.

Cashier PINs

Optional. If a cashier has a PIN set, it must be entered before their shift can be saved — so entries are tied to a verified person.

App Lock PIN

Optional. When set, this 4-6 digit PIN must be entered once per browser session before the app can be opened at all — a lightweight lock to keep casual passers-by out. Leave blank to disable (no PIN screen shown). This is separate from the Owner password, which still separately protects Owner Insights and deleting a Cash Bill.

Backup & Restore

Save all shift records, settings and cashier PINs to a single file, or restore from one — useful if this device is ever reset or replaced.

Everything (records, photos, settings) is saved in this browser's local storage on this device — not on a server — so it's private to this device unless you back up and restore. Browsers typically allow ~5 MB per site.

Used the app with sample numbers while trying it out? This permanently deletes every saved shift record on this device (all the numbers entered so far) so you can start clean. Business profile, branches, default field names, cashier PINs and other settings are kept.

Owner Access

Protects "🔒 Owner Insights" (combined KPIs across both branches). Separate from cashier PINs. Type a new password here to set/change it.

Cloud Sync (Google Sheets)

Optional. Mirrors every saved shift into a Google Sheet you control, so it's viewable from any device — not just this one browser.

Locked to prevent accidental changes — this URL controls where your shift data is sent. Click Edit to unlock it.

First-time setup (once, ~5 min):
  1. Create a Google Sheet (sheets.new).
  2. Extensions > Apps Script, delete any sample code, then paste in the Code.gs that came with this app.
  3. Deploy > New deployment > type "Web app" > Who has access: "Anyone" > Deploy, then authorize when prompted.
  4. Copy the Web App URL (ends in /exec) and paste it above.
Updating after a code change (2 steps):
  1. Paste the new Code.gs over the old one in the same Apps Script project.
  2. Deploy > Manage deployments > Edit (pencil) > Version: New version > Deploy.

The URL stays the same when updating this way — only making a brand-new deployment changes it. Full instructions: "Cloud Sync Setup Instructions" that came with this app.

One-time setup (free): this needs a small "Google Apps Script" web app tied to a Google Sheet you own — ask for the "Cloud Sync Setup Instructions" that came with this app, or search "Google Apps Script web app" for how to create and deploy one, then paste its URL above.

The app works fully offline either way — nothing here is required for daily use. Cloud Sync just also mirrors saved shifts to your Sheet in the background; if it fails (no internet, wrong URL) the shift is still saved locally and queued to retry, never lost.

How The Numbers Are Calculated

Read-only — shown so you can see exactly how every figure on screen is derived. This is financial logic, so it isn't editable here; changing it would mean editing the app itself.

Grand Total (Tray Balance's "Grand Total" and the Total Summary's "Grand Total" are kept identical) =
(₹500+₹200+₹100+₹50+₹20+₹10+₹5+₹2+₹1 Denomination Total) + (Card Pay + UPI Pay + Pluxee) − Opening Balance − Cash Added − Extra Change Given + Change Left by Customer
Total (Total Summary panel) = Grand Total + Expenses Total + Owner Bills Total + Vendor Payments Total + Staff Bills Total
Final Sale = Software Sale (Vasy) + Unbilled Total
Tally / Variance = Total (Total Summary) − Final Sale. Zero means a perfect tally (shown in green); any other amount is shown in red.
Expense Total = sum of every amount entered in the Expenses table.
Staff Bills Total = sum of every amount entered in the Staff Bills table (items a staff member takes now and pays for later, by cash or salary deduction). Treated identically to Vendor Payments in every total below — it is added into Comb. Total and into the Total Summary's "Total" the same way. Each row's Bill # is a reference-only field (the original software/POS bill number this purchase corresponds to) and never affects any calculation.
Comb. Total (Owner/Vendor/Staff/Unbilled combined) = Owner Bills Total + Vendor Payments Total + Staff Bills Total + Unbilled Total.
Tray Balance total (denomination total) = sum of (note/coin value × quantity) across all ₹500 down to ₹1 rows.
Total Digital Payments = Card Pay + UPI Pay + Pluxee.
Total Cash Added = sum of every quantity × denomination value entered in the "Cash Added" float top-up rows.
Closing Balance (when not typed in manually) = sum of (value × quantity) for only the ₹200-and-below denomination rows (₹200, ₹100, ₹50, ₹20, ₹10, ₹5, ₹2, ₹1) — the ₹500 notes are excluded, since those are usually banked rather than kept in the tray as float.
